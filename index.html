常见问题

关于企业部署、安全隔离与定制扩展的核心解答。

系统是否支持私有化部署与本地代码库隔离？

支持。平台采用控制面与执行面分离架构，支持本地 Git Worktree 隔离开发与企业私有 Docker 集群部署。

企业现有飞书与 GitHub 流程如何无缝接入？

通过飞书长连接与多维表格中台，可直接将立项审批、任务看板及 GitHub 分支交付串联，无需额外切换后台。

是否支持按企业规范定制品牌视觉与内容？

支持。所有前端模板均遵循现代 Web 语义化标准与 CSS Design Tokens，可快速定制主题色、版式与模块。
